# ADR 003: Hosting del MVP

- **Estado**: Aceptado (pendiente de ejecutar el despliegue)
- **Fecha**: 2026-11-01
- **Contexto previo**: [ADR 001](ADR_001.md) §2.1 dejó el proveedor de hosting para un ADR posterior;
  [ADR 002](ADR_002.md) definió la app (FastAPI + PostgreSQL/PostGIS + React).

## 1. Contexto

La app ya es una PWA. Para instalarla en un celular el navegador exige **HTTPS**, así que hay
que publicarla. Es un proyecto escolar: el costo debe ser **$0** y lo debe poder desplegar
cualquier integrante sin tarjeta de crédito.

## 2. Decisión

| Parte | Proveedor | Plan |
|---|---|---|
| Frontend (PWA estática) | **Vercel** | Hobby (gratis) |
| API (FastAPI) | **Render** | Web Service Free |
| Base de datos (PostgreSQL 16 + PostGIS) | **Neon** | Free |

- Se despliega la rama `main`; cada push se publica solo.
- La configuración vive en el repo: [`render.yaml`](render.yaml) y
  [`frontend/vercel.json`](frontend/vercel.json). Los secretos (`DATABASE_URL`,
  `FACFOOD_JWT_SECRETO`) viven solo en Render.
- Mismo motor de base de datos que en local (PostgreSQL + PostGIS), como pedía el ADR 001.
- Pasos: [docs/DESPLIEGUE.md](docs/DESPLIEGUE.md).

## 3. Alternativas consideradas

- **PostgreSQL gratis de Render** — descartado: la base gratis caduca a los 30 días.
- **Railway** — descartado: ya no tiene plan gratis permanente.
- **Fly.io** — descartado: pide tarjeta de crédito.
- **Todo en Render** (frontend como sitio estático) — viable; se prefirió Vercel por su CDN y
  por separar el frontend de la API, que se duerme en el plan gratis.

## 4. Consecuencias

- **Positivas**: $0, HTTPS automático, despliegue continuo desde `main` y la PWA instalable.
- **Riesgos / Limitaciones**:
  - La API gratis se duerme tras ~15 min sin uso; la primera petición tarda 30–60 s.
    La PWA mitiga parte con el catálogo en caché.
  - Límites del plan gratis de Neon (almacenamiento y cómputo) — suficientes para la demo.
  - Las cuentas son personales: quien despliegue debe compartir el acceso con el equipo.
  - Región en EE. UU.: algo de latencia desde CDMX, aceptable para el MVP.
